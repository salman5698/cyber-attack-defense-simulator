# cyber-attack-defense-simulator
Interactive educational cybersecurity simulator demonstrating cyber attacks, defensive controls, and network security concepts.
The project provides both **Defender** and **Attacker** modes, allowing users to explore cybersecurity concepts from both perspectives without targeting real systems.

## 🚀 Features

- Interactive Defender Mode
- Interactive Attacker Mode
- Simulated network environment
- CIA Triad monitoring
- Security control deployment
- Attack logs and simulation results
- Different difficulty levels
- Cyber attack and defense reference section

## ⚔️ Cyber Attacks Covered

CyberSim demonstrates concepts related to:

- Phishing
- SQL Injection
- Cross-Site Scripting (XSS)
- DDoS
- Ransomware
- Man-in-the-Middle (MITM)
- Brute Force & Credential Stuffing
- Trojan & Spyware
- Privilege Escalation
- ARP & DNS Spoofing
- Insider Threats
- Social Engineering
- Unpatched Vulnerabilities

## ▶️ How to Run

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Select Defender, Attacker, or Reference mode.
4. Explore the simulated cybersecurity scenarios.

No installation or external server is required.
